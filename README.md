## 第一个分析项目

分析 Uniswap 单个交易池近 30 天的交易行为。链、协议版本、交易池和固定起止时间在选题时确认，尚未选定。

研究问题：
1. 交易量变化来自更多地址参与，还是单笔金额变化？
2. 交易量是否集中在少数地址？
3. 有多少地址在不同日期重复参与？

交付物：SQL、指标定义、数据核验记录、看板链接和短报告。

## 分析约定

- 使用中文解释，关键术语附英文。
- 查询前确认表、字段、数据粒度和来源；不把未运行的查询当作验证结果。
- 明确链、合约、协议版本、时间范围和时区，默认按 UTC 统计链上时间。
- 区分地址与用户、交易与事件、授权与兑换。
- 核对代币精度、美元价格来源、空值和 JOIN 后重复计数。
- 报告区分事实、推断及待验证假设，说明局限。
- 学习使用公开历史数据，不需要投入资金；不保存私钥、助记词或 API 密钥。
